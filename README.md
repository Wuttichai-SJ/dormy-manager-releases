# Dormy Manager — ดาวน์โหลด

- ไฟล์ติดตั้ง: [Releases](https://github.com/Wuttichai-SJ/dormy-manager-releases/releases)
- เว็บดาวน์โหลด: https://wuttichai-sj.github.io/dormy-manager-releases/

- `.github/workflows/pages.yml` — deploy `site/` ขึ้น GitHub Pages เมื่อ `main` เปลี่ยน
